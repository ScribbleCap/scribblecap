# M4-5 Capture Inside the App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Capture button and menu that freeze the screen, let the user pick a region or window in our own overlay (portal dialog on Wayland), and open the result in the editor, with an optional capture folder and auto-save.

**Architecture:** Rust (`app/src/capture/`) owns the flow: hide the editor, freeze every display through the `capture` crate, open one overlay window per display, crop the selection from the frozen pixels, show the editor again. Overlay and countdown windows are extra Tauri webview windows that load the same UI bundle and choose their view from the URL query. Pure geometry and naming live in small, OS-free modules tested on every platform.

**Tech Stack:** Rust 1.99 (workspace), Tauri 2, `tauri-plugin-dialog`, `chrono` (already in the lockfile, now direct), Svelte 5 + TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-24-m4-5-capture-design.md`, read it alongside this plan.

## Global Constraints

- `core` stays UI-free and platform-free; capture OS code stays in `crates/capture`; overlay/window code lives in `app` and `ui`.
- Capture-trait calls are blocking: run them in `tauri::async_runtime::spawn_blocking`.
- Pixels: Rust → UI via `SCIM` (`shell::packet`), UI → Rust via `SCOP` (decision 0014). No JSON pixel arrays.
- 256 MiB RGBA limit per image (as `shell::packet`).
- **Every exit path shows the editor again** (success, cancel, error, panic in a worker).
- Capture file name: `Screenshot YYYY-MM-DD HH.MM.SS.png`; if taken, `Screenshot YYYY-MM-DD HH.MM.SS.mmm.png`; if that is taken too, wait 1 ms and retry. Never overwrite a file the app did not create for this capture. No ` (2)` counters.
- Auto-save is **off** by default. Settings: *Capture save folder*, *Auto-save captures*.
- Timer choices: 3, 5, 10 seconds.
- Unsaved-work prompt buttons, in this order: **Save…**, **Discard**, **Cancel**.
- Clean room: no material from `re-work/` or Skitch; all visuals are new SVG/CSS (no SF Symbols, Segoe Fluent, Material or traced artwork); no capture sound; no other product's name in UI, files or messages.
- New direct dependency: `chrono` (MIT OR Apache-2.0), `default-features = false, features = ["clock"]`, recorded in decision 0015 and the PR.
- All AGENTS.md checks must pass. In an agent sandbox run pnpm with `export XDG_RUNTIME_DIR="${TMPDIR:-/tmp}"`.

## Review Focus

1. **Mixed-DPI and Windows system-DPI setups:** a selection maps to the right pixels on every display. Map with the frozen image's size ÷ the display's point bounds, never `CapturedImage::scale` (Windows reports the system scale on every monitor). Test in Task 1.
2. **The editor never stays hidden:** an error while freezing, a closed overlay window, or a panicked worker still shows the editor. Test the `EditorHidden` guard in Task 3.
3. **A click without a drag in Region mode** does nothing (the overlay stays open); it is not a 0×0 capture. Test in Task 4.
4. **The capture folder vanished or became read-only** between captures: the next save or auto-save asks for a folder again instead of failing. Test in Task 2.
5. **Display layout changed** (monitor unplugged, scale changed) before Previous region: it falls back to the Region overlay. Test in Task 1.

**Files:**
- Create: `app/src/capture/session.rs`
- Modify: `app/src/capture/mod.rs` (commands), `app/src/shell.rs` (`Session` gains `capture_name: Option<String>`), `app/src/output.rs` (`shell_save_image` uses it), `app/src/main.rs` (manage `CaptureState`, register commands), `app/capabilities/default.json`, create `app/capabilities/capture.json`

**Interfaces:**
- Consumes: Task 1 geometry, Task 2 naming and `ensure_capture_folder`, `scribblecap_capture::backend()`, `shell::packet`, `shell::remember`, `core::canvas::transform` (Crop).
- Produces:
  - `pub struct EditorHidden<F: FnMut()>`: constructed after hiding the editor; its `Drop` calls the stored `show` closure exactly once (also on panic/early return). `fn new(show: F) -> Self`.
  - `pub struct Frozen { pub display: DisplayInfo, pub image: CapturedImage }`; `pub fn freeze(capturer: &dyn Capturer) -> scribblecap_capture::Result<Vec<Frozen>>` (every display via `capture_screen(Some(id))`).
  - `pub fn crop(frozen: &Frozen, rect: ScreenRect) -> Result<RasterImage, String>` (via `to_pixels` + `transform(Crop)`).
  - `#[derive(Default)] pub struct CaptureState(pub Mutex<CaptureInner>)` with `frozen: Vec<Frozen>`, `windows: Vec<WindowInfo>`, `previous: Option<PreviousRegion>`, `cancel: Arc<AtomicBool>`, `result: Option<RasterImage>`.
  - Window labels: overlays `capture-overlay-<display id>` at `index.html?overlay=<id>`; badge `capture-countdown` at `index.html?countdown=<seconds>`. Overlays: borderless, always on top, positioned and sized to the display bounds, not resizable, skip taskbar. Badge: 120×120 points, bottom-right of the display under the pointer, always on top, borderless.
  - Constant `HIDE_SETTLE_MS: u64 = 150`: wait after hiding the editor or closing the badge before freezing.
  - Commands (all return `Result<_, String>`):
    - `shell_capture_state() -> CaptureAvailability { wayland: bool, previous: bool }`
    - `shell_capture(mode: CaptureMode) -> Option<Response>`; `CaptureMode` = `"region" | "window" | "screen" | "previous"` (serde, lowercase). Screen (the display under the pointer, from `AppHandle::cursor_position()` and `display_at`), Previous (when `still_valid`; otherwise it opens the Region overlay) and every Wayland mode return the `SCIM` packet directly. Hide only the `main` window (`WebviewWindow::hide`), never the whole app. Region and Window open the overlays and return `None`; the result arrives later via event.
    - `shell_capture_timer(seconds: u8)`: only 3, 5 or 10; hides the editor, shows the badge, waits (checking `cancel` every 100 ms), closes the badge, waits `HIDE_SETTLE_MS`, then runs Region (Wayland: the portal request).
    - `shell_overlay_info(display: u32) -> OverlayInfo { bounds: ScreenRect, windows: Vec<WindowInfo>, mode: CaptureMode }` (window bounds in desktop points, only those intersecting the display).
    - `shell_overlay_frame(display: u32) -> Response` (`SCIM` packet of that display's frozen image).
    - `shell_overlay_select(display: u32, rect: ScreenRect)`: crop, store `previous` (Region mode only), close overlays, drop frozen pixels, show editor, emit `capture-ready` to `main`.
    - `shell_capture_result() -> Response`: take `result`, `remember(... None, image, None)`, set `capture_name`, apply auto-save, return `SCIM` packet named `capture_title(now)`.
    - `shell_capture_cancel()`: set `cancel`, close overlays and badge, drop frozen pixels, show editor, emit `capture-cancelled`.
  - Auto-save (in `shell_capture_result` and the direct-return path): if `auto_save`, `ensure_capture_folder`; if it returns a folder, write an editable PNG of the capture (no annotations) to `folder/capture_file_name(...)` and set the session `target` to that path. Picker cancelled → no file, capture still opens.
  - Save (in `shell_save_image`, not Save As or Export): if `target` is `None` and `capture_name` is `Some`, use `ensure_capture_folder` and a fresh `capture_file_name` instead of the dialog; picker cancelled → fall back to the normal Save dialog.
  - macOS: if `!has_permission() && !request_permission()`, return the error `Screen capture needs permission. Allow ScribbleCap in System Settings → Privacy & Security → Screen & System Audio Recording, then try again.`
